# Utils

Repositório de scripts para o uso cotidiano, que ajudam a executar tarefas de forma local.

## Ferramentas

| Ferramenta | Descrição |
|------------|-----------|
| [YouTube Downloader](./yt_downloader) | Baixa vídeos do YouTube |

Cada ferramenta tem seu próprio README, com as instruções de como utilizar.

## Como usar

```bash
git clone https://github.com/laissemy/utils.git
cd utils
```

Depois, entre na pasta da ferramenta que quiser usar e siga o README dela.
